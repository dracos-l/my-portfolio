# Personal portfolio

My repository for my personal website, soon to be available at logandracos.com

## Getting started

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Changes update automatically.

## Checks and production

```bash
npm run lint
npm run build
npm run start
```

## Current tech stack

<ul>
    <li> Next.js with Typescript </li>
    <li> Supabase for storage </li>
    <li> Resend for communications </li>
    <li> OpenAI API for content regulation </li>
    <li> Vercel for deployment </li>
</ul>
